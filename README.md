# Microsoft 365 Tenant Lab

Laboratório prático de implementação e administração de um ambiente
Microsoft 365.

## Objetivo

Construir e documentar um ambiente Microsoft 365 do zero,
explorando identidade, gerenciamento de dispositivos,
colaboração, segurança e proteção de informações.

## Tecnologias

- Microsoft 365
- Microsoft Entra ID
- Exchange Online
- SharePoint Online
- Microsoft Teams
- Microsoft Intune
- Microsoft Defender
- Microsoft Purview
- Microsoft Graph
- PowerShell
