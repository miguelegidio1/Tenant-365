# Microsoft 365 Tenant Lab

Laboratório prático de implementação e administração de um ambiente
Microsoft 365.

## Objetivo

Construir e documentar um ambiente Microsoft 365 do zero,
explorando identidade, gerenciamento de dispositivos,
colaboração, segurança e proteção de informações.

## Tecnologias

- Microsoft 365
- Microsoft Entra ID
- Exchange Online
- SharePoint Online
- Microsoft Teams
- Microsoft Intune
- Microsoft Defender
- Microsoft Purview
- Microsoft Graph
- PowerShell
  
## Objetivo profissional

Este laboratório foi desenvolvido para aprofundar conhecimentos
práticos em administração de ambientes Microsoft 365, identidade,
segurança, gerenciamento de dispositivos e serviços em nuvem.

##Etapa 1 - Criar o Tenant

Acesse:

admin.microsoft.com

Clique em:

Iniciar avaliação gratuita
Ou criar uma assinatura Microsoft 365 Developer (se disponível)

Defina:

Nome da empresa
País
Domínio inicial

Exemplo:

empresa365.onmicrosoft.com

Crie uma conta Global Administrator:
admin@empresa365.onmicrosoft.com

Anote:
Usuário
Senha
Tenant ID
